Define Model via Spreadsheet

Upload an Excel spreadsheet (.xls or .xlsx) that defines your data model.

Spreadsheet Format Instructions:
  • Each sheet in the Excel file will be treated as an Entity. The sheet name will be used as the Entity Name.
  • Each sheet must have exactly two columns in the first row (headers):
    • Attribute Name: The name of the attribute/column in the entity.
    • Data Type: The data type of the attribute (e.g., String, Integer, Double, Boolean, Date).
  • Subsequent rows in each sheet should list the attribute names and their corresponding data types.

Example for a sheet named "Products":

Attribute Name | Data Type
---------------|-----------
ProductID      | Integer
ProductName    | String
UnitPrice      | Double
